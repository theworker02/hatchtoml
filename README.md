# hatchtoml

Hatch structured JSON toml payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/hatchtoml/

## Install / run

```bash
git clone https://github.com/theworker02/hatchtoml.git
cd hatchtoml
node src/cli.js
node --test
```
